Interface ouverte pour enquêtes locales, Sontadeg est une borne de sondage anonyme. Libre de droits, elle est pensée pour être jouée dans des espaces publics où lors d'évènements. 

# Description du projet

Pensée pour les espaces publics et les évènements, Sontadeg permet de recueillir la voix d'un public de passage sur une question, avec jusqu’à 6 réponses possibles. La question est écrite à la main par l’administrateur·rice, ce qui laisse une grande liberté : texte, dessin, pictogrammes. Le public de passage répond simplement en sélectionnant une ou plusieurs réponses.

Chaque réponse est enregistrée et horodatée dans la carte ESP32. On peut s’y connecter à tout moment, depuis un téléphone ou un ordinateur, via WiFi, pour consulter les réponses et/ou configurer la borne. Un filtre anti-spam limite les fausses réponses et les journalise séparément. Enfin, les réponses s’exportent et peuvent être visualisées grâce à une application html séparée accessible [sur la page du projet](https://tonyvpck.github.io/Sontadeg/).

Sans écran, le dispositif se veut simple à fabriquer, abordable et le plus sobre possible. L’ensemble est placé sous licence libre (CC-BY-SA) pour que le projet reste une ressource commune et partagée. Les fichiers et les codes sont disponibles et reproductibles. Certaines pièces sont à imprimer en 3D, d’autres à découper au laser et d'autre encore à assembler : rapprochez-vous d’un fablab ou d’un makerspace local pour vous aider dans la reproduction du projet. Le code de l'application se téléverse directement dans l'esp32 depuis le navigateur via [cette page](https://tonyvpck.github.io/Sontadeg/).
